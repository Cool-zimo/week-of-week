需要 repo 权限。数据存在你自己的私有仓库 wow-data 里， 不经过任何服务器。

怎么拿令牌？
  1. 打开 GitHub → 右上角头像 → Settings
  2. 左侧最下 Developer settings → Personal access tokens → Tokens (classic)
  3. Generate new token (classic)，勾选 repo
  4. 生成后复制粘贴到上面（只显示一次）

⚠️ 这一点要先想清楚
你的记录存在私有仓库里，但 GitHub 的免费网页托管只对公开仓库开放。 所以发布时会新建一个公开仓库 wow-view —— 链接拿到的人都能看到，照片也一样。
不想公开就选「只要文字」，或者别发布。
